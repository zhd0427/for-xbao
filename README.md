# for-xbao

一个以日常关心和互动为主题的单页网页，使用原生 HTML、CSS 和 JavaScript 实现。

## 功能

- 根据不同选择展示互动内容。
- 包含拥抱、戳一戳、刮刮卡等页面互动与动画。
- 提供可选的飞书消息上报逻辑。

## 文件结构

```text
.
├── .nojekyll
├── index.html    # 页面、样式和交互逻辑
└── README.md
```

## 本地预览

下载仓库后，用浏览器打开 `index.html` 即可查看页面和交互。项目没有构建步骤，也不需要安装前端依赖。

## GitHub Pages

本仓库已启用 GitHub Pages。发布来源以仓库 **Settings → Pages** 的配置为准；更新相应发布分支中的页面文件后，可在部署完成后查看效果。

## 修改内容

页面文字、配色、动画和选项均在 `index.html` 中维护。

### 可选通知

`report()` 函数负责飞书通知，`FEISHU_HOOK` 为空时直接跳过上报。通知需要网络连接，浏览器是否能发送成功还取决于目标服务的跨域配置。

前端代码和网络请求中的 Webhook 地址对访问者可见。需要通知时，建议由服务端保管机器人凭据并转发请求，同时在页面说明上报的内容；不要将生产 Webhook 或签名密钥提交到公开仓库。

## 项目定位

这是个人网页项目，保留为独立的小作品，方便日后维护和回顾。
